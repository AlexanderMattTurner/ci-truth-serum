- `check-absolute-symlinks` now also rejects a tracked symlink whose target git ignores, such as `node_modules/x` or `.venv/bin/y`. That target is built by a tool and is never committed, so the link dangles on a fresh clone for the same reason an absolute target does. The check asks `git check-ignore`, so it reads your own `.gitignore` rather than a list of tool directory names, and it leaves a target outside the repository alone.
