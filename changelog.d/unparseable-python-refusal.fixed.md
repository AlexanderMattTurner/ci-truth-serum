- Every line-oriented check now reports a Python file this interpreter cannot parse, instead of running its detector over a per-line fallback parse. A hook environment older than the tree is the case that bites: a PEP 701 f-string (nested quotes) is a syntax error before Python 3.12, and each line of the file then parses in isolation as its own module, so a scope-dependent check reads a function-local statement as a module-level one. `check-duplicate-module-constant` reported 60 such lines in one file that way. The refusal names the running version and points at `default_language_version:`, and it matches what the pack already did for shell the bash grammar cannot read.
