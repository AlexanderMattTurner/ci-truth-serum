- Release automation no longer stops when one model credential is exhausted: `release-readiness.sh` and `release-prep.sh` now walk a five-rung credential ladder (`ANTHROPIC_API_KEY`, then `CLAUDE_CODE_OAUTH_TOKEN` and its three fallbacks, all passed through the workflows' `env:`), skipping unset rungs and treating an HTTP 400/401/403 as terminal for that credential only instead of fatal for the run. Neither script requires `ANTHROPIC_API_KEY` up front any more, and when every rung is missing or rejected `release-readiness.sh` derives the bump from the pending `changelog.d/` fragment categories and still opens the release PR — announcing the degradation in the log, the job summary, and the PR body rather than reporting a verdict nobody made.
