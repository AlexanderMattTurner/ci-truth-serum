- Every check that reads an opt-out marker out of a workflow now reads it from the file's real comments. A marker anchors on a `#`, and a `#` inside a quoted scalar is a value the workflow's own author writes. A line such as `name: "deploy  # allow-no-timeout: not really"` switched the check off, and the check reported nothing. Twenty-six checks carried that hole: `check-always-reporter`, `check-claude-model`, `check-conclusion-coverage`, `check-cron-comment`, `check-divergent-action-pins`, `check-env-symmetry`, `check-externalized-markers`, `check-frozen-head-sha`, `check-job-timeout`, `check-path-gate-deps`, `check-pin-comment-truth`, `check-pr-paths`, `check-required-event-closure`, `check-required-reporter`, `check-reusable-permissions`, `check-sparse-checkout-closure`, `check-static-concurrency`, `check-token-fallback`, `check-trusted-base`, `check-uncached-download`, `check-unreferenced-local-uses`, `check-unscoped-tool-grant`, `check-untrusted-exec`, `check-unused-reusable-input`, `check-workflow-refs`, and `check-workflow-run-branch-filter`.
- `check-workflow-refs` reads a workflow's comments with PyYAML's scanner and the bash grammar, in place of a delimiter scan. The scan was wrong in both directions. It read a `#` inside a quoted scalar as a comment, so an opt-out written there suppressed a real finding. It also read `echo "quoted # not a comment"` inside a `run:` body as narration, so it reported a citation nobody wrote.
- A workflow that PyYAML cannot scan now loses every suppression and keeps its findings. The delimiter scan did the opposite: it honoured any marker-shaped text in an unparseable file. Reading such a file for NARRATION keeps the delimiter scan, so `check-workflow-refs` still reports what a broken workflow's comments cite. That is the trade `comment_lines` already makes for Python that will not tokenize.
- A marker written after a block scalar's `|` or `>` is a real comment again. PyYAML's scalar token opens at the indicator, so its span swallowed the rest of that line, and a `description: | # unused-input-ok: <reason>` was blanked with the body below it.
