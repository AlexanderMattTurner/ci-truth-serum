- `check-bare-return-status` (Tier 2): a bare `return` or `exit` hands back the status of the last command that ran, so the `&&` or `||` in front of it decides the value. `A && return` is always 0, and a `||` after a test is always 1. The check requires an explicit `return 0` / `return 1` where the forwarded status is a constant. It never flags `cmd || return`, which forwards the command's own code (127, 42). Opt out with `# allow-bare-return: <reason>`.
