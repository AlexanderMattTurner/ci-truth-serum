- `check-flock-fixed-fd` (Tier 1, honesty): flags `flock <number>` in a file that never opens that file descriptor. The number is a name every process in the same descriptor table shares, so such a lock depends on a caller having opened that exact number. When nothing opened it, `flock` exits non-zero and a `set -e` caller dies at a line that reads like a lock acquisition. When something else holds it, the lock guards a different file, both runs proceed, and the job still reports success. Open the descriptor in the file that locks it, and let the shell pick the number: `exec {lock_fd}>FILE`, then `flock -x "$lock_fd"`. The documented pairing `exec 9>FILE; flock 9` passes, and so do a path operand and a computed descriptor. Opt out with `# allow-fixed-fd: <reason>`.
