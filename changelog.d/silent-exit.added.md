- `check-silent-exit` (tier 2): the check flags a literal `exit N` that a failed file or string probe reaches with nothing printed first, such as `[[ -f "$cfg" ]] || exit 2`. The CI log then holds a red step and no cause. A probe is a unary `[[ … ]]`, `[ … ]` or `test` question. A comparison such as `[[ $failed -eq 0 ]]` is not a probe, because it reads a verdict that the script reached earlier. The check skips an exit inside a subshell, a pipeline or a list run with `&`, a `return`, and a branch that runs any command other than an assignment before the exit. Opt out with `# allow-silent-exit: <reason>`.
