- The shared helper modules now carry a `_cts_` prefix (`_fastyaml` is `_cts_fastyaml`, and so on for the other eight). Each check imports its siblings by bare name, and that import reads Python's module cache before it reads the search path. A consumer repository that put its own `_fastyaml.py` on the path and imported it first therefore owned the cache entry, and this pack bound to the consumer's module. The prefix keeps these names off any name a consumer picks. No hook id, entry point or console script changes. A consumer that imported one of these helpers directly must update the name.
