- `check-moving-runner-alias` (Tier 1, identity): the check refuses `ubuntu-latest`, `macos-latest`, `windows-latest` and their larger-runner forms in a workflow or composite action. GitHub moves each alias to a new OS release with no commit in your repository, so CI changes under an unchanged diff. Name the release instead, such as `ubuntu-24.04`. Opt out with `# allow-moving-runner-alias: <reason>`.
