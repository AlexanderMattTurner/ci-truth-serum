- The shell checks now see the commands inside a negated brace group, such as `if ! { docker build . >/dev/null 2>&1; }`. tree-sitter-bash 0.25.1 reads `! { a; }` as a command named `{` with `a` as its argument, so each check saw `{` and missed the real command. For this reason, `check-stderr-suppression` missed the line above. The checks now read the group as a negated subshell. A check that asks whether a group runs in its own shell reads this group as if it did.
- The shell checks now see the commands after `! if`, `! while`, `! until`, `! for`, `! select` and `! case`. Each check reads these statements as not negated, because the grammar cannot hold the `!` there.
- A file with more than 32 levels of nested negated groups (`! { ! { …`) now raises `PathologicalInputError`, because each level costs one more parse.
- `check-pipefail-grep-pipe` and `check-stderr-merge-parse` now read the status of a `{ …; }` or `( … )` group that ends with the statement, and of a redirected statement. `check-pipefail-grep-pipe` now flags `if { producer | grep -q pat; }; then`. `check-stderr-merge-parse` no longer flags a capture in `if { out=$(cmd 2>&1); }; then` or in `if ( out=$(cmd 2>&1) ); then`.
