- `check-unpaged-all` (Extras): it bans an all-shaped verdict over one page of a GitHub listing. GitHub answers a listing under a `total_count` envelope, and one page holds 100 rows, so `all(...)`, `any(...)`, `.every(...)` or `.some(...)` over that page reads a longer listing as a pass. The check fires on a file that reads the GitHub API, names a listing key (`jobs`, `check_runs`, `workflow_runs`, `artifacts`, `check_suites`, `workflows`), reduces a list, and mentions no paging. It reads Python through `ast` and JavaScript or TypeScript through tree-sitter. Opt out with `# allow-unpaged-all: <reason>`.
