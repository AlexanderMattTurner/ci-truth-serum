- `check-secondary-checkout-imports`: a new Tier 2 lint. It fails a job that checks out a second tree with `actions/checkout` `path:`, runs a JavaScript or TypeScript file out of that tree, and installs no Node dependencies anywhere in the job, when that file carries a bare import. The second tree has no `node_modules`, so the import is `ERR_MODULE_NOT_FOUND` on the runner and nowhere else. The lint reads the `run:` body through the bash grammar, follows one shell hop (`bash dir/x.sh` whose script runs `node …`), and reads the imports through the ECMAScript grammar. A job with `npm ci`, `pnpm install`, `yarn`, `bun install`, `actions/setup-node`, `pnpm/action-setup` or `oven-sh/setup-bun` is out of scope. Opt out with `# allow-secondary-checkout-import: <reason>` on the step that runs the script or on the checkout step.
- `check-relative-imports`: `specifiers()` now returns every static specifier of a file, and `relative_specifiers()` filters it. The hook's own verdicts do not change.
