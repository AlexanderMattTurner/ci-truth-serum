- 21 new checks, moved here from the two repositories that each carried their own copy. Shell: `check-bare-mkdir`, `check-env-arith`, `check-curl-retry`, `check-retry-loop`, `check-unbounded-waits`, `check-shell-source-declarations`, `check-dead-shell-functions`. Python: `check-cwd-scoped-git`, `check-unspecified-encoding`, `check-duplicate-module-constant`, `check-duplicate-class-names`, `check-big-tuple-annotations`, `check-unreset-module-state`, `check-sleep-as-sync`, `check-positional-git-argv`, `check-test-helper-kwargs`. Two languages: `check-wall-clock-assertions`, `check-relative-imports`. Workflows: `check-sparse-checkout-closure`, `check-path-shadowed-interpreter`. Shell, Python and workflow `run:` blocks together: `check-truncating-pr-json`. Each sits in a tier aggregate, so a consumer that enables `check-tier1`, `check-tier2` or `check-extras` gets it with no config change.
- Every path, helper name and directory list the ported checks hard-coded is now a flag. `check-curl-retry` takes `--retry-wrapper`, `check-retry-loop` takes `--retry-helper` and `--wrapper`, `check-unbounded-waits` takes `--bounding-wrapper` and `--remote-subcommand`, `check-shell-source-declarations` takes `--search-path` (your shellcheck `-P` roots), `check-duplicate-class-names` takes `--scope`, `check-test-helper-kwargs` takes `--helper-package`, `check-sparse-checkout-closure` takes `--dep-dir`, `check-path-shadowed-interpreter` takes `--agent-action`, `check-big-tuple-annotations` takes `--min-elements`, and `check-unreset-module-state` takes `--reset-name`. A check that scoped itself to a directory now reads the files your `files:` regex hands it.
- `check-sparse-checkout-closure` follows a served Python entrypoint's own local imports. A job whose sparse-checkout list named the script but not the modules it imports died on the runner, and no check saw it: sparse-checkout sets `SKIP_WORKTREE` on the excluded entries, so `git ls-files` still reports a complete tree.
- `check-relative-imports` is Python now. It was a Node script that needed the `typescript` package; it reads the same grammar through the tree-sitter binding this pack already installs, so the hook needs no Node toolchain.
- None of the ported checks carries a grandfathered baseline. Each one fails on any hit.
