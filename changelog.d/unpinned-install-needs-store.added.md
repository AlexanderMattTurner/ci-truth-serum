- `check-uncached-download` now also reports an install from a moving package index, such as `apt-get install -y curl` with no version or with a `pin-exempt` reason. Every run asks the package host, so a slow or dead host turns the job red. A cache must restore the store of the installer before the install, under a key that hashes the file that lists the packages, or under a per-run key with `restore-keys`. The check reads apt, pip, pipx, `uv tool` and global npm installs.
- `check-versionless-install` now reads apt options before the `install` verb, as in `apt-get -qq install curl`. Before, it did not see those installs.
