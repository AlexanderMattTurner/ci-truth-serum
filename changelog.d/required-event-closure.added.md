- New Tier 2 hook `check-required-event-closure`: every job that a `# required-check: true` job transitively `needs` must run on every event the check gates (`pull_request`, `pull_request_target`, `merge_group`). GitHub counts a `skipped` check run as a satisfied required check. A needed job whose `if:` shuts it off on a gating event therefore turns the check green there with none of its work done. The live case is a `decide` job that skips in the merge queue while its `always()` reporter reads the empty outputs as a clean skip. The hook parses the `if:` expression and evaluates it with only the event facts bound; every other context is unknown. A fork guard, a `needs.decide.outputs.*` gate, or a status function is therefore unknown and never fires it. On the repository that motivated the hook it flagged the three real defects and nothing else. Opt out per job with `# event-scoped-ok: <reason>`.
