- **BREAKING**: the symlink hook id is now `check-absolute-symlinks`. It was `check-symlinks`. Rename the `- id:` line in your config to keep the hook enabled. The old id was the same string as the `check-symlinks` hook in `pre-commit/pre-commit-hooks`. The two hooks ask different questions. The upstream one rejects a symlink whose target does not exist. This one rejects a symlink whose target is an absolute path. A repo that enabled both ran two hooks under one id, so `pre-commit run check-symlinks` could not select one of them. The packaged script moves with the id, from `ci_truth_serum/check_symlinks.sh` to `ci_truth_serum/check_absolute_symlinks.sh`.
