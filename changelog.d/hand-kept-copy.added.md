`check-path-list-closure` (extras, `correctness`) flags a bash array of repo paths that a script ships, when a shipped shell or Python file names a tracked file that the array leaves out. Only a directory the array picks single files out of is read, so a tree that the array never touches stays quiet. An array that expands another (`"${PAYLOAD[@]}"`) is followed to its source. The hook scans the whole tracked tree on each run, so a change to a consumer alone still reaches the array. Suppress one consumer line with `# path-list-closure-ok: <reason>`.
