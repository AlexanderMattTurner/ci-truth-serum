- **`check-embedded-program-length`** is new. It flags a python, node, perl or ruby program that a shell script or a workflow `run:` value passes as `-c`/`-e` text, feeds from a heredoc, or holds in a variable. No linter reads such a program, so it ships unchecked. The check reads the bash grammar, so a program inside a message string or a data heredoc does not count. A program longer than 5 significant lines or 200 characters fires. Change the limits with `--max-lines` and `--max-chars`, and name a wrapper command with `--wrapper NAME`. A `run:` value that `check-inline-run-length` already reports is left to that check. Opt out with `# allow-inline-program: <reason>`.
