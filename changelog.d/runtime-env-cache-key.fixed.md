- `check-uncached-download`: a cache key that reads `env.NAME` is now unreadable when an earlier `run:` step computes NAME, no `env:` block sets it, and the name does not say it holds a pin. Such a key covers every download in the job, as any other unreadable key does. Before, the check read only the name and found no pin in it. On agent-glovebox, the advisory-gate cache computes its key as `_GLOVEBOX_ADVISORY_CACHE_KEY` from a hash of the pin files, and this removes three false positives. A key that reads a name such as `env.TOOL_VERSION` still names that pin.
