- Every check now parses YAML with libyaml's `CSafeLoader` when the installed PyYAML ships it, through one new module (`ci_truth_serum/_fastyaml.py`). PyYAML's pure-Python parser was the pack's largest single cost, because `run_tier` gives each selector member its own subprocess and each member re-parses the whole workflow tree. On this repo's 41 tracked YAML files, one parse pass drops from 278 ms to 24 ms. On a consumer with 87 workflow files, it drops from 0.809 s to 0.068 s. The pack falls back to the pure-Python loader when the wheel has no libyaml. Both loaders build the same documents and set the same line and column marks, so a finding keeps its line.
