- New Tier 2 hook `check-reusable-permissions`: a job that calls a local reusable workflow with `uses: ./.github/workflows/…` must grant every permission that workflow asks for. GitHub refuses to start a called workflow that requests more than its caller holds. One permission added to a shared workflow therefore stops every caller at once, and the error names the callee, which is correct as written. The check compares the two static `permissions:` blocks. It follows the call one more hop when the middle job declares no block of its own. It also reports a caller that declares no block at all, because the token then carries the repository default, which the workflow file does not state. Suppress one calling job with `# reusable-permissions-ok: <reason>`. A `./` path with no file on disk is its own hard error.
