- `check-uncached-download`: a cache key that hashes a file holding the pin's value now names that pin. A generated pin file, such as a `tool-versions.sh` rendered from `config/tool-pins/<tool>.json`, carries the same value as its source, so a key that hashes the source changes whenever the pin does. On agent-glovebox this removes one false positive, the k3s download in `vm-live-boot.yaml`, and changes no other finding.
