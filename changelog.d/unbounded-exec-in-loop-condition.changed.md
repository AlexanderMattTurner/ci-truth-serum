- **`check-unbounded-waits`** now also fires on a runtime `exec` call in the condition of a `while` or `until` loop, such as `until docker exec c true; do sleep 1; done`. A wedged runtime makes that readiness poll spin forever. The built-in tools are `docker`, `podman`, `nerdctl`, `kubectl`, `sbx`, `lxc` and `incus`. Add another with `--exec-tool NAME`. The check reads the condition through the bash grammar, so it also finds the call under `!`, in an `&&`/`||` list, in a pipeline and inside `$(…)`. A `timeout` or a registered `--bounding-wrapper` before the tool bounds the call, and `# allow-unbounded: <reason>` opts it out. An `exec` call outside a loop condition stays out of scope.
