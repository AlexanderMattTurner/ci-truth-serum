- `check-unreferenced-local-uses`: reports a local composite action, or a workflow whose only trigger is `workflow_call`, that nothing in this repository runs. The check walks `uses:` from the files that run without a caller, so two dead definitions that call each other are both reported. Such a definition never runs, and it still reads to the next author as a live code path. Name an external caller with `# unreferenced-ok: <reason>`.
