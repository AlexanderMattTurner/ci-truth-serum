- `check-test-predicate-shadow` (Extras): flags a shell test that redefines a production **pure predicate** — a function whose body only tests and returns. Stubbing a dependency stays legitimate; a predicate has no side effect to intercept, so redefining one substitutes the test's own (usually weaker) copy of the logic and the shipped predicate can regress unseen. Purity is decided on the real bash grammar, so anything richer than a flat `[[ … ]]` / `(( … ))` / `return`/`true`/`false` chain reads as impure and is never flagged. Opt out with `# predicate-shadow-ok: <reason>`.
