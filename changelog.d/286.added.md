- `check-redirect-order` (Tier 1 · Honesty): the check refuses an input redirect that comes before the redirect that silences stderr, as in `cmd <"$f" 2>/dev/null`. Bash applies redirects from left to right, so when the open of `$f` fails, bash prints the error before stderr is silenced. In one merge queue, this printed error failed a build when a `/proc` entry vanished before a read. Write `cmd 2>/dev/null <"$f"`, or group the command as `{ cmd <"$f"; } 2>/dev/null`. Heredocs, here-strings, `</dev/null`, `<&2` and `<&-` pass. Opt out with `# allow-redirect-order: <reason>`.
