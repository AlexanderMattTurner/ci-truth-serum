- `check-uncached-download`: a Python file that runs `curl` or `wget` through `subprocess` now counts as a download. This includes a `bash -c` script that sources a repo shell library, which the check reads with the arguments the script receives. A module that a script imports through a `sys.path` entry that another imported module adds now resolves too. A cache whose key names the pin no longer covers a download when the cache's `path:` cannot hold the file that the download writes.
