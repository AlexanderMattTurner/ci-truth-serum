- `check-uncached-download`: a Python file that runs `curl` or `wget` through `subprocess` now counts as a download. This includes a `bash -c` script that sources a repo shell library, which the check reads with the arguments the script receives. A download in an imported module counts only when the file calls the function that holds it. A module that a script imports through a `sys.path` entry that another imported module adds now resolves too.
