- The shared redirect reader now reads the `0` in `cmd 0>f` as the descriptor of the redirect. Before this fix, it read that redirect as a redirect of stdout, because the bash grammar parses the `0` as an argument of the command.
- `check-stderr-suppression` now reads `>&/dev/null` and `2>|/dev/null` as redirects of stderr to `/dev/null`. Before this fix, `docker build . >&/dev/null` passed, though `>&` with a file target moves both stdout and stderr.
