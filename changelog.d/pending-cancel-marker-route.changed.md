- `check-pending-cancel-concurrency` now reads a workflow that declares a required check with a `# required-check: true` marker alone. Before this change the check read only the decide-gate plus `always()`-reporter shape, so a marker-only workflow passed while it carried the exact hazard. On the marker route the check reads the workflow-level `concurrency:` block plus the marked jobs only: an advisory job in a marked workflow reddens no required check.
