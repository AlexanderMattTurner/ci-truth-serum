- The tier aggregates (`check-tier1` / `check-tier2` / `check-extras`) now name the checks that had no file to scan. A content lint reads only the files it is given, so a commit that touches one language leaves the other content lints with nothing to do — and they exited 0, the same code as a pass. A hand run with no file arguments hit the worst form: every workflow lint ran, no content lint did, and the run reported a clean tier. The note goes to stderr and lists each check by name. When the caller passed no files at all, it also gives the command that scans the whole tree.
