- `check-always-reporter` and `check-required-reporter` now accept a fail-closed twin job on a gated workflow. A twin's condition is `always() && needs.<gate>.result != 'success'`, with `||`-joined disjuncts for several gates. GitHub skips the twin on a healthy run, so it boots no runner, and a skipped conclusion satisfies a required check. The twin runs red only when a decide gate did not succeed. `check-required-reporter` demands the same `# required-check:` classification for a twin as for an always() reporter.
