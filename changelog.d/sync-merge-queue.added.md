- `sync-merge-queue` console script: it holds a repo's merge queue rule at parameters that can still merge. It pins `grouping_strategy` to `ALLGREEN` unless you pass `--allow-headgreen`, and it writes `1` over a `max_entries_to_merge` or `max_entries_to_build` that is zero or absent. A positive size is a human's tuning and survives. The script reports three states it must not repair, and exits non-zero on each: a ruleset that is not enforced, a queue whose `merge_method` the repo forbids, and a ruleset with no always-on bypass for the merge queue app. Each state stops every merge while nothing turns red. `--skip-bypass-check` drops the last of the three. `--check` reports the drift and writes nothing. A repo whose branch ruleset carries no merge queue rule exits 0.
