- The annotation window again accepts the line directly above a construct when that line also carries code. Consolidating the window onto one definition narrowed it by accident: the block above was walked through comment-only lines, so a reason written as a trailing comment on the line that opens the construct — `if  # pin-exempt: <reason>` above a `curl` — stopped counting, and the check fired at an annotation that was already there. The window is now the construct's span, the line directly above it whatever that line holds, and the unbroken comment block above that.
