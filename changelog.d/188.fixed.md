- `sync-required-checks`: an HTTP error from the GitHub API now names the method, the endpoint, the status and GitHub's own message, instead of raising a bare `urllib` traceback. A write refused with 403 or 404 also names the missing `administration: write` grant, because GitHub hides an admin endpoint a token may read but not write behind a 404 rather than a 403.
- `sync-required-checks`: a repository whose only branch ruleset is organization-owned now fails with that reason. It previously returned that ruleset's id and sent the write to the repository endpoint, which answers 404 — the same shape as a missing ruleset or an under-scoped token, so the real cause was unreadable.
