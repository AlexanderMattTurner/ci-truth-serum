- `actions/mute-failure-guard`: a JavaScript action that you add as the first step of a job. It points `BASH_ENV` at a guard that records failed bash commands in a ledger, with the file, line, status and command text. The ledger has three kinds of row: a failed command, a `$(…)`, `<(…)` or `( … )` that exited non-zero, and a failure that `|| true` or `|| :` discarded. The second kind also records a substitution that fails inside an `if` or a `||` list, where bash runs no ERR trap. When the job fails, the action prints the failed step's ledger rows and the last 50 distinct rows, with repeats counted. It also prints the step's status and signal, `ulimit -n`, the open-file count and the process count. A failed step that printed no error text gets its own `mute failure` error.
