- `check-uncached-download` (Tier 2): reports a job that downloads a version-pinned tool and holds no cache. The pin makes the bytes identical on every run, so each push to each pull request pays for the same fetch, and a slow registry turns that cost into a job timeout GitHub reports as “cancelled”. Local composite actions are inlined first, so a job that caches through a shared setup action counts as cached. An unpinned install is left to `check-versionless-install`. Opt out with `# cache-exempt: <reason>`.
