- `release-prep.yaml`: the version-bump job read its bootstrap script (`.github/scripts/release-prep-bump-version.sh`) out of the pull request's own checkout, so a PR that rewrote that file executed with `TEMPLATE_SYNC_TOKEN_ORG` and the model credentials in its environment — the staging that script performs never applied to the script itself. The job now stages the bootstrap from the base ref and runs that copy. Found by dogfooding the new `check-untrusted-exec` hook.
