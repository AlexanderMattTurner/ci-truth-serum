- New Extras hook `check-workflow-refs`: fails when a doc or comment cites a GitHub Actions workflow file that no longer exists under `.github/workflows/` — the rot left behind when workflows are consolidated or renamed, invisible to link checkers because the citation is a bare basename (`release-prep.yaml`). Reads only comment bodies and non-fenced prose, resolves against the git-tracked workflow set, and ignores a basename that matches any tracked file or that an ecosystem reserves for something else (`pnpm-lock.yaml`, `compose.yml`, `action.yaml`); a bare basename counts only inside `.github/` or on a line carrying CI vocabulary, while a `.github/workflows/<name>.ya?ml` path always counts. `CHANGELOG.md` and `changelog.d/` are skipped as audit records, and a cross-repo reference is suppressed with `allow-workflow-ref: <reason>`.
