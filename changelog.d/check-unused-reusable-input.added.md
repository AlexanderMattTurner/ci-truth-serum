- `check-unused-reusable-input` (Extras): reports a `workflow_call` input that no local caller passes in a `with:` block. Such an input is either dead surface — described, threaded into a step's `env:`, and never set by any run — or the shared answer nobody wired, and the second is what grows a duplicate implementation: a decide gate shipped a `paths-regex-file` input built to read a trigger regex out of a shell file, no workflow passed it, and a sibling workflow needing exactly that grew a 65-line bespoke script with its own copy of the range resolution, the draft skip and the path match. A reusable workflow that no local job calls is skipped, because its callers may live in another repository and this tree cannot see their `with:` blocks. Suppress one input with `# unused-input-ok: <reason>` on its key line or a direct-child line; the reason is mandatory, and a placeholder such as "n/a" fails.
