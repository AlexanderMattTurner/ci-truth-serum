- `check-path-gate-deps` reads a decide call that passes `derive-paths-regex: true` as not applicable for the dependencies it discovers by itself. Those are a local composite action a step `uses:`, and a `.github/scripts/…` path a `run:` body names. That input asks the decide job to widen the committed value with the closure of the jobs it gates when it runs, so the committed value is only a seed. A path declared with `# gate-deps:` is still matched against that seed. The comment exists for a dependency no static scan reaches, and the run-time derivation is a static scan too.
