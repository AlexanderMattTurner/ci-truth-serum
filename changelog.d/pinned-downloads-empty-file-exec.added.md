- `check-pinned-downloads` now also flags a `# pin-exempt`'d download whose first later use runs it — `bash`/`sh`/`source`/`.`/`chmod +x` on the saved file — with no `[[ -s FILE ]]` (or equivalent) check between the download and the run. An empty file (a 200 response with an empty body, a dead proxy, a full disk) makes `curl -f` report success and the run exit 0 having done nothing, so the install silently reports success and installs nothing. Opt out with `# empty-download-ok: <reason>`.
