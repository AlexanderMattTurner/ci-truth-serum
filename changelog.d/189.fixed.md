- `sync-required-checks` and `sync-merge-queue`: a write against a repository whose only branch ruleset is organization-owned now fails with that reason. Both resolve the ruleset through the same lookup, which previously returned that ruleset's id and sent the write to the repository endpoint, which answers 404 — the same shape as a missing ruleset or an under-scoped token, so the real cause was unreadable. A `--check` run writes nothing, so it still reads an organization-owned ruleset and reports drift.
