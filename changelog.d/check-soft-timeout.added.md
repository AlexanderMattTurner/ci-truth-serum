- **`check-soft-timeout`** (Tier 1 · Honesty) — a time limit that the bounded command can ignore. At the deadline, `timeout 60 cmd` sends SIGTERM. A command can catch that signal, block it, or never reach its handler. The command then runs past the limit, and whatever waits on it keeps waiting. Two measured escapes: an `npm` install blocked on a dead registry socket outlived a 180-second limit by 8 minutes 36 seconds; a wedged sandbox held an incident kill switch on its first target while every later target kept running. `--kill-after=N` schedules SIGKILL, which no process can catch, and that makes the limit real. The check reads the bash grammar, so it finds three positions a text search misses or misreads: the command `timeout 60 cmd`, the wrapped call `sbx exec box -- timeout 60 cat /x`, and the array form `run=(timeout 600)` that the shell expands later. A `timeout` inside a message string or a heredoc body is text, and the check ignores it. `-s KILL` passes, because it sends the unstoppable signal first. Opt out with `# allow-soft-timeout: <reason>`.
