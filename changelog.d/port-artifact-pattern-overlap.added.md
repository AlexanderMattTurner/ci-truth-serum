- **`check-artifact-pattern-overlap`** is a new workflow check. It fails when one `actions/download-artifact` `pattern:` matches the names of two different uploads in the same workflow run. The download then merges both artifacts into one input, and the next step reads a file of the wrong shape. A matrix of uploads counts as one upload. The check follows local composite actions to the upload or download they make. `# artifact-pattern-ok: <reason>` in the download step opts it out.
