- `check-external-clock-targets` (extra): a host outside GitHub can fire a repository's sweeps on a clock it owns. The clock reads a manifest of workflow file names and dispatches each one. The hook fails an entry that names a missing workflow, a workflow with no `workflow_dispatch` trigger, or one with a required default-less input. Each such entry drops every dispatch with no red mark. The default manifest is `.github/scheduler/sweeps.txt`; override it with `--manifest PATH`.
