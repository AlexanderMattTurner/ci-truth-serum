- `check-required-reporter`: a job marked `# required-check: true` whose `name:` holds a `${{ matrix.* }}` reference now fails when the job can skip. Two things skip it: its own `if:` closes, or a job it `needs:` skips. `sync-required-checks` registers one context per matrix combination, and GitHub posts those check runs only when the job runs. Each context then stays "Expected — Waiting for status to be reported", so the branch blocks with no red check and no log. To pass, make the job unconditional and gate its steps. Or add a sibling job that runs on `if: always()`, carries the same `name:` template and covers the same matrix. A `uses:` job is no such sibling, because GitHub names its check run `<caller job name> / <called job name>`. "Can skip" over-approximates, so a guard that never closes on the protected branch takes `# matrix-context-ok: <reason>` on the job.
