- `check-required-reporter`: a job marked `# required-check: true` whose `name:` holds a `${{ matrix.* }}` reference now fails when the job can skip. Two things skip it: its own `if:` closes, or a job it `needs:` skips. `sync-required-checks` registers one context per matrix combination, and GitHub posts those check runs only when the job runs. Each context then stays "Expected — Waiting for status to be reported", so the branch blocks with no red check and no log. To pass, make the job unconditional and gate its steps. Or add a sibling job that runs on `if: always()` and carries the same `name:` template. The rule reads the marker with the same unconditional scope as the `uses:` rule — every workflow, any trigger, no opt-out.
