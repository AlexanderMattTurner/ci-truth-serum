- `check-select`: run the checks a `--select` expression names, by tag (`tag:security`), by tier (`tier:1`), or one at a time (`check:check-job-timeout`), minus any `--ignore` values. Tags say what a check is about, so a security-focused consumer no longer has to read all three tiers to find the security lints. The README lists the 14 tags; `ci_truth_serum/_registry.py` holds the per-check metadata.
