- `check-required-reporter`: a job marked `# required-check: true` now fails when its `name:` holds a `${{ }}` that is not a matrix reference. `sync-required-checks` substitutes only `${{ matrix.* }}`, so it registers the rest of the name as literal text. GitHub evaluates every expression before it posts a check run. So no run reports the registered context, and the branch blocks with nothing red to read. To pass, give the job a static name, or move the marker to a static-named `always()` reporter that `needs:` the job.
