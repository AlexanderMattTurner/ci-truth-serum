- `check-required-reporter`: a job marked `# required-check: true` now fails when a check context it registers still holds a `${{ }}`. `sync-required-checks` substitutes only `${{ matrix.* }}`, with the matrix values as written, so any other expression — in the `name:` or in a matrix value — stays in the registered text. GitHub evaluates every expression before it posts a check run. So no run reports the registered context, and the branch blocks with nothing red to read. To pass, use a static name and static matrix values, or move the marker to a static-named `always()` reporter that `needs:` the job.
- `check-required-reporter`: a marked job also fails when its `name:` references a matrix key that its `strategy.matrix` never defines. The sync can expand no context from that name, so it requires nothing for the job, and the marker silently stops gating merges. An axis with a dynamic `${{ fromJSON(...) }}` value counts as defined.
