- `check-absolute-symlinks` now splits each index entry in bash and no longer starts three processes for each tracked file. On a checkout with 6,552 tracked files and 2 symlinks, the run time went from 66 seconds to 0.4 seconds. The check now reads paths byte-exact, so it reports a symlink whose path holds a tab or a newline by its real path. Before, git quoted such a path and the report named the quoted form.
