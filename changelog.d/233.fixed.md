- `check-absolute-symlinks` now splits each index entry in bash and no longer starts three processes for each tracked file. On a checkout with 6,552 tracked files and 2 symlinks, the run time went from 66 seconds to between 0.2 and 0.5 seconds.
- `check-absolute-symlinks` now fails when `git ls-files` fails, for example outside a repository. Before, it read an empty index and passed.
- `check-absolute-symlinks` now reads each path and each link target byte-exact. It reports a symlink whose path holds a tab or a newline by its real path. It also keeps a newline at the end of a target. Before, git quoted such a path, and the report named the quoted form.
