- `.ci-truth-serum.toml`: a file at the repository root that gives each check in a tier aggregate its flags. Each `[checks.<check>]` table names one check by its hook id or module name, and its `args` list reaches the check before its file arguments. Every tier hook and `check-select` read it, and `--check-arg` flags follow the configured ones. A table that names no aggregated check, a key other than `args`, or a file that does not parse makes the run fail with exit status 2.
