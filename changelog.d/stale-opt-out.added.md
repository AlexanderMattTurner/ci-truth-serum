- `check-stale-opt-out` (standalone, not in a tier aggregate): the check reports an opt-out annotation that suppresses nothing. It runs each covered check again on the file with every opt-out ignored. An annotation that no finding reaches is stale, and you fix it by deleting it. The check reads each comment through the grammar of the file's language, so a token inside a string or a heredoc body is never an annotation. A check that refuses a file makes the run fail. The check skips a token that an uncovered check also reads. It also skips `check-relative-imports`, because that verdict depends on files that the commit does not hold.
