- `check-drift-guards` now reads the MODULE docstring of a Python test file. The intent-phrasing route read function docstrings only, so an author who moved the sentence to the top of the file — "these tests must stay in sync with the live config" — hid the guard from all three routes at once: the tests below such a sentence need neither a guard name nor a comparison the structural route can see. A declaring module docstring produces one finding on the file, because the sentence names no single test. A module-level `pytestmark = pytest.mark.drift_guard("<why no SSOT is feasible>")` justifies it, and pytest applies that marker to every test in the file, so it answers for the guards under it too. A file with no `test_*` function is never judged this way: a lint that DETECTS drift describes what it detects in its own module docstring.
