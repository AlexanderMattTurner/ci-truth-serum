- `scripts/assemble-changelog.mjs` inserts the assembled release section with a function replacer. `String.prototype.replace` expands `$$`, `$&`, `` $` ``, `$'` and `$1` in a replacement string. A changelog fragment holds arbitrary prose, so it can contain any of them. In `$'`, the pattern means "the text after the match". One fragment quoted a shell `$'…'` string, and the assembler copied the whole rest of `CHANGELOG.md` into the middle of the new section. That broke the v1.1.0 cut: the release PR duplicated the `## [1.0.0]` block inside its own `### Fixed` list, and the split bullet failed `markdownlint` MD038.
