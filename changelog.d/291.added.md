- `check-uncached-download` now also reads an install that runs in a machine the job starts: an image built from a repo Dockerfile, a Lima guest that a repo template provisions, and a `docker run IMAGE sh -c BODY` container. In those machines it reads apk, dnf, yum, zypper and pacman as well as apt. A registry cache (`cache-from`) is the store of an image. The check also reports a cache that can never fill, because its `env:` path starts with `~/` and bash does not expand that tilde from a variable.
