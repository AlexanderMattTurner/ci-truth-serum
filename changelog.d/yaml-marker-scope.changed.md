- A marker inside a `run:` script no longer suppresses a check whose finding is about the JOB or the FILE. A script's comment talks about the script, and one step's script must not speak for its neighbours. Move such a marker beside the key it is about. The checks that judge the `run:` line itself still read the script: `check-frozen-head-sha`, `check-job-timeout`, `check-path-gate-deps`, `check-sparse-checkout-closure`, `check-trusted-base`, `check-uncached-download`, `check-unscoped-tool-grant`, and `check-untrusted-exec`.
- `check-pin-comment-truth` no longer reads a `#` glued straight onto the SHA. YAML calls `uses: owner/action@<sha>#v4` one value with no comment in it, so the `v4` there is neither a version claim nor an opt-out. Put a space before the `#` to get the comment back.
- `check-externalized-markers` reads a composite action's manifest as YAML. An opt-out in `action.yml` must sit in a real comment or in a `run:` block scalar's body. A `.sh` source is still read as written, because every `#` in a script opens a comment.
