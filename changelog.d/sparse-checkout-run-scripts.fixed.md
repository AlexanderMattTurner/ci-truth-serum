- `check-sparse-checkout-closure`: follows each script that a shell script runs (`bash "$SCRIPT_DIR/x.sh"`, `"$DIR/x.py"`), and reads the steps of each local composite action that a job uses. Before, the check followed only `source` lines and the job's own `run:` steps. A job whose list omitted a script that another script ran passed the check and then failed on the runner. In a composite action, the check reads `$GITHUB_ACTION_PATH` as the action's directory, and a checkout in the action ends the steps that the sparse list must serve. An `action.yml` that is not valid YAML is now a violation. Before, it added zero steps, and the job passed.
