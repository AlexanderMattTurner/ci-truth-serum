- `check-uncached-download` now follows the repo scripts that a step runs. It reads each `bash` script and each sourced file, follows each function call into the function body, and parses each Python file that the step gives to an interpreter. A download that the job checks against a digest (`sha256sum -c`) now counts as pinned. A cache now covers a download only when its `key:` names the pin, or a file that sets the pin, or when its `path:` holds the download. A cache with a key or path that the check cannot read still covers the whole job. Expect new findings in jobs that get a pinned tool through a script.
