- The shell lints and `trace-ci` now read a command word after bash's quote removal. So `\make`, `ma"ke"` and `/dev/'null'` read as `make` and `/dev/null`. Before this fix, only one pair of quotes around the whole word was removed, and a lint did not see these commands.
- A `command -v` lookup now counts only when the `-v` comes before the command, or in a group such as `-pv`. Before this fix, `command docker run -v x:y` counted as a lookup, so the lints that skip a lookup did not check that call. `check-bash32-portability` now also reads `command -x grep` as a command that bash fails, so it runs no `grep`.
