- Every check now asks one function where an opt-out annotation may sit. `_linecheck.annotation_window` is that function: it accepts the construct's own span plus the unbroken comment block directly above it. The pack previously held about twenty open-coded answers — some accepted the line above, some a whole logical line, some only the flagged line — so the same annotation was honoured by one check and rejected by its neighbour, and an author could not learn the rule once. A wrapped reason now counts everywhere, because prose wraps and the token line moves with it. The window stays bounded: the token must sit in a real comment, it must carry a reason, and the block stops at the first line that is not a comment, so a blank line ends it and an annotation written about something else cannot drift onto a later construct. A contract test bans reaching for a neighbouring line by hand, so the twenty answers cannot grow back.
