- `check-cron-staleness-optout` (Extras): fails a scheduled workflow that nothing answers "does this still RUN?" for — GitHub disables a dormant repo's schedules after 60 days, and a `startup_failure`/`skipped`/`cancelled` run is not a failed run, so a failure notifier stays silent while the guard is dead. Enforces the `# cron-stale: false  # <reason>` marker discipline (`# cron-alert: false` deliberately does not satisfy it); `--watchdog-workflow FILENAME` requires the named runtime watcher to exist under `.github/workflows/` and itself be schedule-triggered, and `--require-stale-marker` demands a marker on every scheduled workflow (narrowed to the watchdog itself when a valid one is declared; a watchdog that also fires on a non-`schedule:` trigger — which GitHub's dormancy disable cannot kill — is treated as covered and owes no marker, so a runtime sweep reading the marker as an opt-out is never forced to drop the watchdog from its own watched set). Without flags only a present-but-malformed marker is reported.
