- **`check-tier1`, `check-tier2` and `check-extras`** use less CPU and less wall-clock time on a large tree. Their findings and exit codes do not change. On a consumer with 856 shell files and 2614 Python files, on 4 cores, the three aggregates used 321 s of CPU before and 174 s after. Their wall-clock times went from 88 s, 33 s and 168 s to 11 s, 24 s and 42 s.
  - `check-argument-exit-swallow` reads and parses each sourced library once per run. Before, it parsed each library again for every script that sources it.
  - The checks that read Python share one parse, one walk of the tree, and one tokenize pass of each file. Before, each check did its own. Five of these checks no longer print a `SyntaxWarning` from the Python compiler.
  - The per-file pass runs in worker processes, one for each core, when it has 64 files or more. The output keeps the order of one serial pass.
