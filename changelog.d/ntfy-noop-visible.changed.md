- `notify-ntfy`: each path that notifies nobody now writes a `::warning::` annotation, which GitHub shows on the run summary. There are two such paths, and both stay non-fatal for the reasons they always had: an unset `GH_NTFY_SUBJECT` secret must not redden a repo that never opted in, and a dead ntfy server must not add a second red to a workflow that already failed. The cost of that choice was that a green notifier run proved nothing — the alert may have reached a phone, or the topic may have been empty all year, and the run looked the same either way. The annotation separates the two without changing any exit status. The topic stays out of the output; the annotation names the server and the `curl` exit code only.
