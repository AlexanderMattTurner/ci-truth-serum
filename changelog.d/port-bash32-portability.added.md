- `check-bash32-portability`: flags GNU-only flags (`grep -P`, `sort -V`, `date -d` and others) and bash-4+ syntax (`declare -A`, `mapfile`, `${v,,}` and others) in shell scripts that must run on macOS. The check reads the bash grammar, so a quoted string or a heredoc body never counts. It judges every file you pass it, so name your macOS scripts in the hook's `files:`. Use `--only bsd` or `--only bash32` to run one rule set, and opt out of one line with `# bash32-portability-ok: <reason>`.
