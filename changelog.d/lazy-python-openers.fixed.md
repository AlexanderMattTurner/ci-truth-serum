- The Python comment reader computes its opener lines only when an opt-out lookup first reads them. Before, it ran a second tokenize, parse and tree walk for every Python file, and most files have no finding to look up. Over 3,639 Python files, `marker_comments` took 48.9 s with the eager computation and 15.0 s without it. That cost pushed a consumer's lint job past its 5-minute timeout.
